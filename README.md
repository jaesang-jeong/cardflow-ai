# CardFlow AI - 헤드라인 투 소셜 카드뉴스 스튜디오 🚀

> **기사 링크(URL) 한 줄을 입력하면 기사 내용을 스마트하게 요약하고, 알맞은 대표 이미지를 자동으로 배치하여 출처, 작성일, 해시태그까지 완벽하게 입력해주는 올인원 카드뉴스 제작 애플리케이션입니다.**

Inspired by Lovable's `headline-to-social-story`.

---

## ✨ 핵심 주요 기능

### 1. 🔗 기사 링크(URL) 자동 파싱 & 본문 추출
- **전체 언론사 지원**: 네이버 뉴스, 다음 뉴스, 연합뉴스, 조선/동아/중앙일보, BBC, CNN, TechCrunch 등 국내외 주요 뉴스 사이트 호환
- **스마트 메타데이터 추출**: 기사 제목(Headline), 언론사(Press), 발행일(Date), 대표 이미지(OpenGraph Image), 본문 내용 자동 정제
- **직접 입력(텍스트) 모드**: 링크 외에도 사용자가 직접 헤드라인과 본문을 붙여넣어 즉시 카드뉴스를 생성할 수 있는 유연한 입력 탭 제공

### 2. 🧠 지능형 AI 요약 & 카드뉴스 구성
- **구조화된 멀티 슬라이드 구성**:
  1. **표지(Cover)**: 시선을 사로잡는 강력한 헤드라인, 카테고리 배지, 후크 서브타이틀
  2. **이슈 배경(Summary)**: "무슨 일인가요?" 발단과 핵심 요약
  3. **핵심 포인트 1~3(Key Details)**: 주요 변화, 수치 데이터, 이해관계자 반응 및 분석
  4. **전망 & 토론(Conclusion)**: 앞으로의 전망과 독자 참여 유도 질문
  5. **출처 & 크레딧(Source Info)**: 원문 기사 언론사, 링크, 보도일자
- **듀얼 AI 엔진 지원**:
  - **내장 무료 한국어 NLP 엔진**: 외부 API 키 등록 없이도 즉시 고품질 카드뉴스 요약 및 해시태그 생성 가능
  - **Google Gemini API 연동**: API 키 입력 시 더욱 창의적이고 섬세한 에디토리얼 카피라이팅 적용 가능

### 3. 🖼️ 알맞은 이미지 자동 매칭 & AI 이미지 생성
- **기사 원문 대표 이미지 자동 연동**: 기사 메타데이터(og:image)를 감지하여 1순위로 배치
- **주제별 맞춤형 고화질 스톡 사진**: 테크, 경제, 환경, 사회, 일자리 등 기사 카테고리에 최적화된 Unsplash 고해상도 이미지 자동 매칭
- **AI 이미지 생성(Pollinations AI)**: 슬라이드별 핵심 문맥을 분석하여 프롬프트 자동 작성 후 1클릭 AI 이미지 즉시 생성
- **배경 어둡기 조절 & 블러 효과**: 텍스트 가독성을 극대화하기 위한 오버레이 명암(0~90%) 및 블러 토글 제공
- **CORS 우회 이미지 프록시**: 외부 이미지 다운로드 시 HTML5 Canvas 캔버스 오염(Taint) 오류 방지 내장

### 4. 🎨 소셜 미디어 최적화 규격 & 프리미엄 테마
- **비율(Aspect Ratio)**:
  - `1:1`: 인스타그램 피드 정방형 (1080 x 1080)
  - `4:5`: 인스타그램 피드 세로형 (1080 x 1350, 피드 점유율 및 클릭률 극대화)
  - `9:16`: 인스타 스토리 / 릴스 / 유튜브 쇼츠용 (1080 x 1920)
- **6가지 컬러 테마**:
  - 🌌 **모던 다크 (Modern Dark)**: 세련된 네온 바이올렛 & 다크
  - 📰 **에디토리얼 네이비 (Editorial Navy)**: 신뢰감을 주는 전통 언론사 스타일
  - ☀️ **클린 화이트 (Clean White)**: 깔끔하고 산뜻한 미니멀 디자인
  - 🥑 **에메랄드 포레스트 (Emerald Forest)**: 친환경, 라이프, 웰니스 스타일
  - 🔥 **선셋 코랄 (Sunset Coral)**: 트렌디하고 주목도 높은 코랄 핑크
  - 💜 **사이버 네온 (Cyber Neon)**: 미래지향적 테크 & AI 스타일
- **워터마크 커스텀**: 내 SNS 채널 계정명(`@today_news_pick`) 자동 각인

### 5. 🛠️ 슬라이드 상세 실시간 에디터 & 시퀀스 관리
- 실시간으로 슬라이드 텍스트, 항목 불릿, 배지, 이미지 변경
- 슬라이드 추가, 복제, 삭제, 순서 이동
- 키보드 좌우 화살표(`←`, `→`) 단축키로 슬라이드 간편 전환

### 6. 📱 모바일 피드(인스타그램) 인터랙티브 시뮬레이터
- 실제 스마트폰에서 카드뉴스가 어떻게 보일지 피드 UI(좋아요, 댓글, 캡션, 슬라이드 스와이프)로 실시간 시뮬레이션

### 7. 📥 원클릭 고화질 내보내기 & 캡션 복사
- **전체 카드 일괄 ZIP 다운로드**: 모든 슬라이드를 고화질 PNG(`01_cover.png`, `02_issue.png`...) 및 캡션 텍스트 파일(`caption_and_tags.txt`)로 묶어 압축 다운로드
- **현재 카드 PNG 저장**: 단일 슬라이드 즉시 저장
- **SNS 캡션 & 해시태그 원클릭 복사**: 인스타그램 게시물 작성 시 바로 붙여넣을 수 있는 서식 완성본 복사

## 🧩 크롬 확장 프로그램 (Chrome Extension) 설치 및 사용법

웹서핑 중 기사 링크를 일일이 복사할 필요 없이, **보고 있는 뉴스 기사 탭에서 아이콘 클릭 한 번으로 즉시 카드뉴스를 제작**할 수 있습니다!

### 설치 방법 (30초 완료)
1. 크롬 브라우저를 열고 주소창에 `chrome://extensions` 입력 후 이동합니다.
2. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 파일 탐색기에서 다음 폴더를 선택합니다:
   ```
   C:\agy\social_card\extension
   ```
5. 크롬 툴바에 **CardFlow AI** 📰 아이콘이 추가됩니다!

### 주요 기능
- **⚡ 현재 탭 1초 자동 추출**: 네이버, 다음, 조선, 연합, BBC 등 보고 있는 기사 페이지에서 아이콘을 누르면 기사 제목, 언론사, 대표 사진, 본문을 즉시 읽어와 카드뉴스를 자동 생성합니다.
- **사이드 패널(Side Panel) 지원**: 기사를 읽으면서 우측 패널에서 카드뉴스 수정 및 미리보기를 동시에 진행할 수 있습니다.
- **오프라인/자체 실행**: 웹 서버가 꺼져 있어도 확장 프로그램 단독으로 요약, 이미지 매칭, 고해상도 ZIP/PNG 다운로드가 가능합니다.

## 🚀 웹 애플리케이션 빠른 시작 방법

### 실행 요구사항
- Node.js 18 이상 (또는 v26 LTS 권장)
- pnpm 또는 npm

### 1. 의존성 설치
```bash
pnpm install
```

### 2. 빌드 및 서버 실행
```bash
# 프로덕션 빌드 & 실행
pnpm build
pnpm start
```

서버가 구동되면 브라우저에서 **`http://localhost:3000`** 접속하여 카드뉴스를 제작할 수 있습니다.
